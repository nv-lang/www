Nova Oracle 0.1.0 (alpha)

Oracle компилирует Nova в C, затем в нативный код. Дистрибутив содержит CLI nova, стандартную библиотеку и C-рантайм; в бинарные архивы также входит nova-lsp. Windows-архив прошёл проверку после чистой распаковки с Boehm GC по умолчанию, Linux-архив — после чистой распаковки на x86_64. Для сборки программ в Linux нужны C-компилятор и заголовки Boehm GC.

Nova Carina 0.2.1 (alpha)

Carina — компилятор, написанный на Nova. Эта альфа для Windows x86_64 собрана из исходников ревизии 3729abcce: опубликованный Oracle 0.1.0 сначала собрал стадию A, та выпустила C-код, а Clang собрал из него опубликованный исполняемый файл стадии B1. Для этой ревизии B1 и новый закреплённый seed достигают одной неподвижной точки на уровне C: 13 250 302 байта, SHA-256 25c5404f1e8e175652f19c9ca6cb03d29de82cee70a7cd9f4258c6724115c8a0. По этому критерию на уровне C Carina 0.2.1 можно собрать, не запуская Oracle; обязательный CI-гейт всё ещё использует Oracle. Это не означает побайтового совпадения нативного исполняемого файла со стадией B2, поддержки Linux или готовности экосистемы пакетов (планируется для 0.3). Для сборки программ Nova по-прежнему нужен внешний C-компилятор. Исторические заголовки Boehm GC взяты из опубликованного Oracle 0.1.0; сохранённые runtime-библиотеки — из run2/source3729. Это описано в расписке и заметках о выпуске. Файл release-notes.md — снимок до этой проверки; обновлённое пояснение — в текущем тексте релиза.

Зачем 0.2.1? 0.2.0 подтвердила неподвижную точку для прежней принятой ревизии. 0.2.1 закрепляет новый seed ревизии 3729abcce и подтверждает его неподвижную точку на уровне C; отдельная успешная эмиссия старого seed не доказывает такой же неподвижной точки.

Nova Carina 0.2.0 (alpha)

Carina — компилятор, написанный на Nova. Принятая на Windows x86_64 двойная сборка A → B → C дала побайтно одинаковые B и C, а также одинаковый сгенерированный C. Windows-архив содержит сохранённый novac.exe стадии B, не новую пересборку. Ступень 0.2 доказывает самосборку, а не готовность широкой экосистемы пакетов: это критерий 0.3. Linux-бинарника Carina в 0.2.0 нет: сборка Linux CI не является распиской двойной сборки на Linux.
